# منصة حفظ القرآن الكريم
## Quran Learning & Memorization Platform

منصة احترافية ومتطورة لتعليم وحفظ القرآن الكريم مع واجهة إسلامية أنيقة وعصرية.

### 🎯 المميزات الرئيسية

#### 1. **نظام الحفظ المتقدم**
- اختيار السورة والآيات المراد حفظها
- تشغيل التلاوة مع خيارات التكرار
- تسجيل التسميع عبر الميكروفون
- تحليل الأداء باستخدام التعرف الصوتي
- متابعة تقدم الحفظ اليومي

#### 2. **الاستماع للقراء**
- مكتبة تلاوات لأكثر من 50 قارئ معروف
- بحث متقدم عن القراء والسور
- تشغيل صوت عالي الجودة (320kbps)
- خيارات التحكم (السرعة، التكرار، الخلفية)

#### 3. **تحميل المصحف الشريف**
- مصحف المدينة المنورة
- مصحف ملون للتجويد
- مصحف للأطفال بخط كبير
- أجزاء منفصلة (جزء عم وغيره)
- مصاحف معلقة مع تفاسير

#### 4. **لوحة التحكم الشخصية**
- عرض إحصائيات الحفظ اليومية والأسبوعية
- متابعة السور المحفوظة
- نظام الإنجازات والشارات
- رسوم بيانية للتقدم

#### 5. **التصميم والواجهة**
- تصميم احترافي بروح إسلامية حديثة
- ألوان هادئة: أخضر داكن، ذهبي، بيج
- دعم اللغة العربية الكامل
- تصميم مستجيب (Responsive) لجميع الأجهزة
- دعم الوضع الليلي
- تأثيرات انتقالية ناعمة

### 🛠️ التقنيات المستخدمة

**Frontend:**
- Next.js 16 - Framework React حديث
- React 19 - مكتبة واجهات المستخدم
- Tailwind CSS 4 - تنسيق احترافي
- Framer Motion - تأثيرات حركية
- Lucide React - أيقونات جميلة

**البنية:**
- TypeScript-ready structure
- Component-based architecture
- CSS-in-JS مع Tailwind
- PWA-ready (يمكن تحويله لتطبيق جوال)

### 📁 هيكل المشروع

```
app/
├── page.jsx                    # الصفحة الرئيسية
├── layout.jsx                 # تخطيط الموقع الرئيسي
├── globals.css                # أنماط عامة
├── components/
│   ├── Header.jsx            # رأس الصفحة
│   ├── Footer.jsx            # تذييل الصفحة
│   ├── AudioPlayer.jsx       # مشغل الصوت
│   ├── RecordingWidget.jsx   # أداة التسجيل
│   ├── ProgressTracker.jsx   # متتبع التقدم
│   └── QuranSelector.jsx     # منتقي السور
├── memorization/
│   └── page.jsx              # صفحة الحفظ
├── listeners/
│   └── page.jsx              # صفحة القراء
├── downloads/
│   └── page.jsx              # صفحة التحميل
├── dashboard/
│   └── page.jsx              # لوحة التحكم
└── about/
    └── page.jsx              # صفحة عن الموقع

public/
├── images/                    # الصور والرسومات
├── audio/                     # ملفات صوتية
└── pdfs/                      # ملفات PDF

Configuration Files:
├── next.config.js            # إعدادات Next.js
├── tailwind.config.js        # إعدادات Tailwind
├── postcss.config.js         # إعدادات PostCSS
└── package.json              # الحزم والمكتبات
```

### 🚀 البدء السريع

#### التثبيت
```bash
npm install
```

#### تشغيل خادم التطوير
```bash
npm run dev
```

الموقع سيكون متاحاً على `http://localhost:3000`

#### البناء للإنتاج
```bash
npm run build
npm start
```
